Cost Optimization Tool powered by Agentic AI

An Agentic AI system that watches GCP spend, pinpoints waste and recommends optimization actions — paired with a Regulatory Reporting workstream for compliance delivery.

The problem

A large enterprise running hundreds of GCP services across BigQuery, Dataflow, GKE and Cloud Composer was leaking spend to idle resources, over-provisioned slots, redundant data copies and inefficient query patterns. Monthly FinOps reviews caught problems weeks after the money was already spent, and recommendations never made it back to the teams who owned the workloads.

Parallel to this, the Regulatory Reporting workstream needed auditable, timely visibility into how data flowed through those same services for compliance filings — the two workstreams shared infrastructure, lineage and accountability.

The approach

Built a multi-agent system where each agent owns a bounded responsibility and hands off structured output to the next:

  • Observer Agent — polls GCP Billing API, BigQuery INFORMATION_SCHEMA, Composer DAG metrics and GKE utilization into a unified cost-signal store.
  • Anomaly Agent — flags cost drift, idle resources, suboptimal slot reservations and runaway query patterns using statistical baselines + Gemini-based reasoning.
  • Diagnosis Agent — correlates anomalies with recent deploys, DAG changes, data volume shifts and ownership metadata to attribute root cause.
  • Recommendation Agent — produces a human-readable action plan with risk tier, estimated savings and the exact owner / Jira project to assign.
  • Reporting Agent — publishes the same evidence trail into the Regulatory Reporting pipeline so compliance and FinOps share one source of truth.

Why Agentic AI (vs. a script)

  • Cost anomalies rarely have a single clean cause — reasoning across billing, lineage and recent changes is naturally agentic.
  • Each stage emits structured facts the next stage can audit — fully traceable, unlike a monolithic LLM prompt.
  • New signals (e.g. carbon footprint, data residency) plug in as additional agents without rewriting the pipeline.

What's next

  • Expand coverage to Vertex AI inference costs and cross-project egress.
